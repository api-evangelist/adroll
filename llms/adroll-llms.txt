# NextRoll API

> The NextRoll API lets developers build marketing applications on top of AdRoll
> and AdRoll ABM (RollWorks). Base URL: https://services.adroll.com.
> Authentication: OAuth 2.0 or Personal Access Token plus client ID. Object
> hierarchy: Organization > Advertisable > Campaigns, Audiences, Ads, and
> AdGroups. Objects are identified by EIDs (alphanumeric external IDs).


2020, NextRoll
